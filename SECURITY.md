# Security

`context-canvas-check` reads configuration files on your machine and never sends anything over the network.

To report a vulnerability, use **Report a vulnerability** on this repository's Security tab (GitHub private vulnerability reporting). Please don't open a public issue. We aim to reply within 7 days.

In scope: anything that lets a crafted configuration file make the checker write outside `~/.context-canvas/`, execute code, or hide a problem it should report.
